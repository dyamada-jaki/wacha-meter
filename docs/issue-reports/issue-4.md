## 2. 目的と範囲

他者主催の会議へ「わちゃメーター」を参加させる前段として、Mac のコマンドから Zoom の Public Client OAuth（PKCE S256・state・loopback）で本人の許可を受け、トークン取得の成否を確かめる。Issue #1 の SDK 認証とは分ける。スコープ外: 会議への参加・退出、OBF、音声、採点、画面、外部配布、課金、Zoom への申請、トークンの保存・自動更新。

### 計画の要点（両者に共通）
- 新しいコマンド `npm run zoom:oauth` は、Mac 上の Node.js だけで動く（Docker・SDK・C++ は使わない）。依存は増やさない
- `127.0.0.1:0` の一時ポートで待ち受ける。戻り先は `http://127.0.0.1:<実ポート>/callback`（Zoom は loopback の戻り先をポートを除いて照合する）
- PKCE S256 と state を毎回作る。state が合わなければトークン要求を送らない。どの経路でも待受を閉じる。秘密の値は出さず、トークンはメモリだけで扱う
- Public Client ID は `.local/zoom-oauth.env`（Git 管理外）に置く。SDK の設定とは分ける
- テストを先に書く。外部とのつなぎ目（ブラウザ・Zoom の認可画面・トークン API）だけを偽物にする
